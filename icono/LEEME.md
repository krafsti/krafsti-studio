# Icono de Krafsti Studio

La K de Krafsti montada con tres piezas geométricas, como se compone en la herramienta: el palo crema, el brazo verde azulado y la pierna roja, sobre el fondo oscuro de la herramienta.

- `icono.svg`: el original, en vectores (256 × 256).
- `icono.ico`: para Windows (16, 24, 32, 48, 64, 128 y 256 px).
- `icono-16.png` … `icono-1024.png`: para Linux y para todo lo demás.

Colores: fondo `#1b1a17`, palo `#ece7dc`, brazo `#3fb3ac`, pierna `#ff6b55`.
